# Shukla Rugs Horizon storefront: homepage sections, collection and product templates

The change completes the Horizon theme customization for Shukla Rugs across three independent template files: `templates/index.json` appends the eight remaining homepage sections after the preserved hero and featured-product list; `templates/collection.json` adds an editorial header and tunes card typography while keeping Horizon's native filter/sort block; `templates/product.json` keeps the native gallery, variant picker, buy buttons, and recommendations while adding a metafield-guarded detail accordion rendered by one new snippet (`snippets/shukla-product-details.liquid`). All sections reuse stock Horizon section types composed through JSON rather than inventing new Liquid sections, and every data-dependent surface is left as an empty merchant-editable picker so nothing production is fabricated. The task's four commits touch only files under `shopify-live-horizon/`.

Watch for: one new Theme Check `OrphanedSnippet` warning on the new snippet (confirmed — a false positive because the snippet is referenced only from a `custom-liquid` string setting the static analyzer cannot trace); the pre-existing `SUKLA RUGS` brand typo lives in a baseline commit below `origin/main` and in `src/`, both out of task scope (confirmed — not reintroduced in any theme file).

**Verdict**: APPROVED

## High-level view

Scope is clean. All 490 diffed files sit under `shopify-live-horizon/`; `src/` and `shopify-theme/` are untouched, and the `SUKLA` visible-text rename is a pre-existing baseline commit, not part of this task's four commits. No push/publish occurred — every commit is local feature work.

The homepage section order in `index.json`'s `order` array (hero, shop_by_room, product_list, shop_by_category, bhadohi_story, brand_statement, design_consultation, reviews, journal, final_cta) matches `src/app/page.tsx` component order exactly, including the deliberate placement of Shop by Room before the featured-product list.

Data integrity holds. The reviews section is a neutral merchant-editable placeholder with no invented testimonials, ratings, or authors. Product detail rows are each `!= blank` guarded against `product.metafields.custom.*` and omit themselves when absent; shipping/returns links render only when a real store policy page is configured. The Next.js mock defaults (Hand-Knotted, 100% Wool, 12-14 Weeks, knot stats, "top interior architects specify") were deliberately not copied. Brand name is spelled "Shukla Rugs" everywhere in the theme.

Native commerce is preserved. Collection keeps the `filters` block with filtering, sorting, and grid density enabled, binding header text to `closest.collection.*`; product keeps `variant-picker`, `buy-buttons`, `product-recommendations`, and the `_product-media-gallery`. Rug proportions are protected by `aspect_ratio: adapt` + `media_fit: contain` on the gallery and `image_ratio: adapt` on collection cards.

Tokens are consistent — palette via `settings.color_palette.*`, fonts via `var(--font-heading--family)` / `var(--font-body--family)`, terracotta `#BC8A5A` used only as a literal eyebrow accent. All three JSON templates parse after stripping the comment banner, and Theme Check introduces zero new errors versus the 2-error/6-warning baseline.

`snippets/shukla-product-details.liquid` guards every row with `!= blank` against `product.metafields.custom.{material,construction,dimensions,care_instructions,origin_region,product_story}` and renders nothing when values are absent. The shipping/returns row links only to `shop.policies.shipping_policy` / `refund_policy` and self-hides when unconfigured. No hardcoded values and no fabricated fallbacks appear; the Next.js mock defaults were deliberately excluded. The metafield namespace/keys are plain top-of-file assigns a merchant can adjust, documented as needing confirmation against the live store's metafield definitions.

### Native commerce preserved

`collection.json` keeps the `main-collection` `filters` block with `enable_filtering`, `enable_sorting`, and `enable_grid_density` all true (confirmed), and header text binds to `closest.collection.title` / `closest.collection.description` with no hardcoded products or invented metafield-backed filters. `product.json` retains `_product-media-gallery`, `variant-picker` (variant_style buttons), `buy-buttons` (stacking/quantity/add-to-cart/accelerated checkout), and the `product-recommendations` section (confirmed). ### Rug aspect ratios

The product gallery uses `aspect_ratio: adapt` with `media_fit: contain`, and collection/homepage collection cards use `image_ratio: adapt`, so rug proportions are not misleadingly cropped (confirmed).

### Tokens and typography

Display headings use `var(--font-heading--family)` (Jost); eyebrows, body, and price use `var(--font-body--family)` (Inter). Section backgrounds use `settings.color_palette.background` / `.foreground` / `.color1` / `.color2`; terracotta `#BC8A5A` appears only as a literal eyebrow text color, consistent with the documented palette convention.

Zero new errors introduced.
